## 📋 Про проєкт

Блог про три улюблені міста України: тихий курорт, культурна столиця заходу й столиця країни. Кожне місто — на окремій сторінці з фото, фактами, визначними місцями та особистою оцінкою. Є форма для пропозиції нових міст.

**Технології:** HTML5 · CSS3 (custom properties) · Git · GitHub Pages

---

## 🗂 Структура проєкту

```
my-best-cities/
├── index.html          # Головна сторінка — вступ і карти міст
├── city-morshyn.html   # Моршин — курортне містечко (оцінка 10/10)
├── city-lviv.html      # Львів — культурна столиця (оцінка 10/10)
├── city-kyiv.html      # Київ — столиця України (оцінка 7/10)
├── form.html           # Форма «Запропонувати місто»
├── style.css           # Єдині стилі для всіх сторінок
└── README.md           # Цей файл
```

---

## 📄 Сторінки

| Сторінка | Опис |
|---|---|
| `index.html` | Головна: вступ, навігація, короткий огляд 3 міст |
| `city-morshyn.html` | Моршин: мінеральні води, Карпати, санаторії |
| `city-lviv.html` | Львів: ЮНЕСКО, кав'ярні, середньовічна архітектура |
| `city-kyiv.html` | Київ: Дніпро, золоті куполи, Печерська лавра |
| `form.html` | Форма: ім'я, email, місто, країна, тип відпочинку |

## 🎨 Дизайн

Кольорова схема побудована на CSS custom properties:

| Змінна | Значення | Застосування |
|---|---|---|
| `--black` | `#121212` | Фон header/footer, рамки |
| `--beige` | `#f2e8d5` | Фон сторінки |
| `--beige-dark` | `#e3d5b8` | Фон article-карток |
| `--gold` | `#c9a227` | Акцент, рамки заголовків |
| `--gold-dark` | `#8a6d10` | Посилання в тексті |
